## 每一行的判定口径

| 结论 | 算通过的样子 | 不算通过 |
|---|---|---|
| **能否打开** | 三个地址都出内容，标题是「主题列表 / 检查台 / 练习记录」 | 只说「能打开」，说不出看到了什么 |
| **能否真实读写** | 做了某个改动 → 刷新 → 改动还在；或看完一条练习记录后，页面上能看到它 | 只看了静态内容，全程没做任何改动 |
| **有无报错** | 按 F12 打开控制台，Console 里 0 条红色报错 | 有报错但「应该是正常的吧」——有就写出来 |

## 「真实读写」具体怎么做（任选一处）

**做法 A · 检查台改数据（最直接）**

1. 打开检查台，找到任意一条练习记录
2. 记下它的错误次数（error count）
3. 在控制台（或者你自己有权限的数据库控制台）把这一项改掉
4. **刷新页面**，看这个数字有没有跟着变

**做法 B · 存一场新的**

1. 首页选一个主题进对话
2. 用文本框发两三句英语
3. 点「结束对话」
4. 去「练习记录」页看这一场在不在列表里

> 做法A 需要能改数据库；若你没有权限，**直接说「只做了打开，没能改数据」**，
> 这不算失分——如实说比硬凑好。
