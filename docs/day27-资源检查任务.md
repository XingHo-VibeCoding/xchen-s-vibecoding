在同一个页面上，把消耗**按产品**看一眼，重点盯这四类（它们对应本项目的四个真实消耗源）：

| 消耗源 | 对应本项目什么 | 怎么看 |
|---|---|---|
| **静态网站托管 / CDN 流量** | 那 4 个页面（`topics/dialogue/result/records`）被打开就消耗 | 明细里的流量项 |

## §3 任务 3 · 记下到期时间（体验版的规则先讲清）

在套餐卡片上找到**有效期**并抄下来。同时知道这几条（官方口径，用于判断"到期前要不要动手"）：

| 规则 | 影响 |
|---|---|
| 体验版提供 **3,000 资源点/月**（1,000 点 ≈ ¥1） | 额度用完即停服，付费环境才会转按量 |
| **单次续费 6 个月**，**到期前 1 个月内**才可以续 | 太早点续费没用；过了期也不能续 |
| **不支持自动续费** | ★ 到期没人管 = 停服 |
| 到期后进入**停服隔离期**，隔离期内未转付费则**销毁环境** | 销毁 = 环境里数据（数据库 / 托管 / 函数）一起没 |
| 免费环境不支持加购资源包、不支持按量付费 | 想扩只能整体升级为付费套餐 |

**你要做的判断**（今天只需记录，不用决定升级）：到期日是几号、离今天还有多少天、够不够撑到打卡结束。

## §4 任务 4 · 导出数据（三张表，各存一份 JSON）

> 这一节就是"备份"，命令出自 `docs/release-v1.0.md §4.3`（Day 26 实测可用）。
> 输出目录 `.deploy/backups/db/` 在 `.gitignore` 的 `.deploy/` 里 → **不会进仓库**（安全）。
> ⚠️ SQL 编辑器单次限 10000 字符；当前数据量远未触限，不必分批。

### 以下是 Git Bash（MINGW64）版

```bash
cd /c/Users/26629/WorkBuddy/VibeCoding
mkdir -p .deploy/backups/db
D=$(date +%Y%m%d)
for t in sessions turns items; do
  tcb db execute -e cxj1528-d4g55ng0o54cbe296 --sql "select * from $t" --json \
    > ".deploy/backups/db/$D-$t.json"
done
ls -l .deploy/backups/db/
```

### 以下是 PowerShell 版

```powershell
cd C:\Users\26629\WorkBuddy\VibeCoding
New-Item -ItemType Directory -Force -Path .\.deploy\backups\db | Out-Null
$d = Get-Date -Format 'yyyyMMdd'
foreach ($t in 'sessions','turns','items') {
  tcb db execute -e cxj1528-d4g55ng0o54cbe296 --sql "select * from $t" --json |
    Out-File -FilePath ".\.deploy\backups\db\$d-$t.json" -Encoding utf8
}
Get-ChildItem .\.deploy\backups\db\
```

★ **PowerShell 的编码坑**：`>` 重定向默认写 **UTF-16LE**，生成的 JSON 又大一倍又读不了。
所以上面用的是 `| Out-File -Encoding utf8`（Windows PowerShell 5.1 会带 BOM）。
**要最干净的结果就用 Git Bash 那一版**（`>` 直接写 UTF-8 无 BOM）。

### 导出成功的判据（三条都要满足）

1. 三个文件都存在、且**非空**：`sessions` / `turns` / `items`
2. 文件里能看到 JSON（打开任意一个，能看到 `[` 或 `{` 开头）
3. **行数与库里的行数对得上** —— 拿 Day 26 的基线比：`sessions` 7 行 / `turns` 20 行 / `items` 8 行
   （出处：`docs/release-v1.0.md §4.3`「现状」一行；今天以实际查到的为准，若多了就是你今天试用产生的，正常）

> 另一条路（备查，不强制）：控制台数据库页面若提供导出功能，可另存一份。
> 本文不写它的具体按钮位置 —— 我没核实过体验版有没有这个按钮，不凭印象写。
