### 二、四类断言（每项给数字，不给「已确认」）

| 断言 | 判据 |
|---|---|
| 横向溢出 | `document.documentElement.scrollWidth > innerWidth` 即出界 |
| 触控目标 | `(A \| BUTTON) && offsetParent !== null`，宽高**任一** < 44 记一条 |
| 文字裁切 | 与出界分开报，别混成一个数 |
| 控制台 | 报错数为 0 |

**豁免**：`.orb`、角斑等刻意停在框外的装饰，**不能算进出界**。

### 三、改动涉及 CSS 时加测

- 四页 × 五断点**无横向溢出**（现有基线：390 / 360 / 640 / 740 / 1440）
- 版面回归基线：**17/17**
- 改按钮高度这类改动：跑 `btn-probe.js <base> <标签>` 做**改前改后对照**
  （只报数字：按钮尺寸 / 卡片高 / 页高）

### 四、交付表述的三条硬要求

1. **禁止**只写「已确认」「检查无误」「应该没问题」
2. 每条结论配**能直接复制粘贴的命令**或**文件路径 + 行号**
3. 结论不能比证据大 —— 说「只追加没删除」就要给出 `deletions` 为 0 的统计

不合格样例：「已经检查过了，没有问题」
合格样例：`node mobile-check.js 390 → 四页六 URL，出界 0 / 裁切 0 / 触控 72 达标 / 控制台 0 报错`

## 踩过的坑（别改回去）

### 1. `hidden` 会被任何显式 `display` 规则覆盖
- 全站已有兜底 `[hidden]{display:none !important}`（在 reset 之后）
- **判定看 `getComputedStyle(el).display`，不能只看 `el.hidden` 属性**

### 2. 一条规则可能同时命中「该成行」与「该独立成行」的元素
- `.counter b{display:block}` 本意让时长数字单独成行，却把「第 1 轮」拆成三行
- 行内的加 `.counter-inline` 显式 `display:inline` 压回
- **验证靠量高度**（> 行高 1.6 倍即断行），不靠肉眼

### 3. `filter` 连外圈 `box-shadow` 一起作用
- 「调暗」用 `brightness`（**不低于约 0.8**）
- **别用 `saturate`** —— 会把浅色高光推向白

### 4. 构图问题量数值发现不了
- 光球 149px 各项数值「合法」但四边空，176px 才成立
- **数值合法 ≠ 视觉成立**，两种检查都要做

### 5. 缩放过的整页图没法用肉眼比间距/尺寸
- Day 12 角斑压字、Day 14 气泡间距不匀，**两次都是量出来推翻了肉眼**

### 8. 收藏同步的做法（P3 / P4）

收藏状态**只有一份**，存在 `localStorage`（`Storage` 的 `favoriteItems` 键）。
页面渲染时**从这一份状态现场算出各个列表**，而不是各存一份。

所以在结果页收藏的条目，打开记录页自然就在收藏区里，不需要任何同步机制；
取消收藏后也能立刻消失 —— 重算一遍即可。

`item-card.js` 的 `pressed` **传函数不传布尔值**：同一`itemId` 可能在两页各有一个按钮，
其中一个被改动后，另一个要能重新从存储取真值校正过来。传死值两边会各说各话。

**`favoriteItems` 少一个 `topicId`** —— 已定不管，别顺手"修"。

## 组件的字段契约

`item-card.js` 用到的字段（口径见 `PRD.md §6.2`）：

| 字段 | 说明 |
|---|---|
| `itemId` | 条目编号，收藏状态的键 |
| `type` | `offtopic` / `logic` / `good` —— 三条分支决定显示什么 |
| `typeLabel` | 胶囊上的文字 |
| `quote` | 用户说过的原话，**不修改、不精简** |
| `turn` | 出现在第几轮 |
| `reminder` | 一句话提醒 |
| `fix` | 纠正的话；**只有 logic 有** |

**为什么 `fix` 用空字符串而不是缺字段**：PRD 明确「偏题条目没有纠正这一格」——
这是**设计**不是缺漏。空字符串表达「这一格本该没有」，渲染时整格不出现；
若JSON 里漏掉字段，则与「刻意为空」无法区分，容易掩盖问题。

偏题与逻辑错误的区别是**口径**不是实现细节：
**偏题只提醒、逻辑错误才给纠正**（`PRD.md §6.2` 第 343 行把「偏题越界做了纠正」列为不合格）。
